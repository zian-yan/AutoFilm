## [Unreleased]

### 🐛 修复

- **[Alist2Strm]**: ISO 原盘同目录的**伴生文件跟随改名**：`xxx.zh-cn.srt`、`xxx.jpg`、`xxx.nfo` 这类文件现在会存成 `xxx.iso.zh-cn.srt` / `xxx.iso.jpg` / `xxx.iso.nfo`。此前 ISO 输出 `xxx.iso.strm`，而字幕仍按原名 `xxx.zh-cn.srt` 落盘，媒体服务器按「视频名去掉 `.strm`」认领伴生文件，结果这些字幕永远不会被挂到片子上。改名以**目录为单位**判断：只有同目录里确实存在被配置成生成 `.strm` 的 `xxx.iso` 时才插 `.iso`，取最长匹配（`A.iso` 与 `A.B.iso` 并存时 `A.B.zh-cn.srt` 归给 `A.B`）、大小写不敏感、已经是 `xxx.iso.xxx.srt` 形态的不重复插；扫描判定 / 写盘 / 同步清理读的是同一份目录上下文，不会出现「写盘叫 A、清理找 B」。升级后老库里按原名存在的字幕会在首次运行重新生成一份改名字幕，若开启了同步清理，旧文件会作为过期文件被清掉。

### 🔧 变更

- **[Admin]**: 面板登录改为**登录一次保持 30 天**（原 12 小时滑动过期，几乎每次打开都要重登）。会话改为**落盘**在 `web.yaml` 同目录的 `.autofilm_sessions.json`，因此版本升级、容器重建、进程重启都不再踢人——这正是「30 天」能否兑现的关键。有效期从登录时刻固定计算、不随访问顺延，浏览器 Cookie 与服务端会话在同一时刻失效，行为可预期；同时有效的会话上限仍为 128 个（超出按最早过期淘汰）。安全性上没有放宽：会话文件与配置文件一样按仅属主可读（0600）原子写入，token 等同凭据、不进仓库；文件里保存**凭据指纹**，用户名或密码改动（无论是在面板里改，还是停机期间直接编辑 `web.yaml`）都会让旧会话全部作废，改密码「踢下线」的语义不变；文件损坏或格式版本不符时按「没有会话」处理，面板正常启动、只需重新登录一次。登录页补了一行 30 天有效期说明。

## [3.4.0] - 2026-11-21

### ✨ 新增

- **[Alist2Strm]**: 全局设置新增 **`strm_ext`（生成后缀）**，可自定义需要生成 `.strm` 的源文件后缀白名单，只有匹配的文件才会产出 `.strm`：此前后缀是写死的视频列表，ISO 原盘镜像（`xxx.iso`）无法生成，加进其它配置又会被当成伴生文件整份下载。它和并发、伴生文件下载一样放在根级 `alist2strm` 段（面板「Strm 任务 → 全局设置」）——「这批库要产出哪些后缀」是整机的公共约定，逐任务抄写只会各自漂移；`alist2strm_tasks` 里同名字段会被忽略并在日志中提示。**ISO 镜像保留源后缀**——`xxx.iso` 输出 `xxx.iso.strm`（媒体服务器据此识别原盘），其它后缀仍为 `xxx.strm`；扫描判定、写盘、同步清理三条流程共用同一份路径规则，不会出现「判定按 A 名字、写盘按 B 名字」而反复重写或误删的情况。后缀大小写不敏感（`ISO` / `.Iso` / `.iso` 等价）、点前缀可省略、重复项自动去重；配置缺失、空列表或全部是空条目时回退默认视频后缀（而不是「一个都不生成」——那样开启同步清理会把本地已有 `.strm` 全部删掉）。同时修复同一后缀既在生成列表又在下载列表时被当成伴生文件反复重下的问题。

## [3.3.2] - 2026-11-19

### ✨ 新增

- **[Admin]**: MediaWarp 配置页新增**运行日志弹窗**，交互与任务日志弹窗一致（固定尺寸、贴底自动跟随、Esc / 点遮罩关闭、定时刷新），并新增两件 MediaWarp 特有的事：**服务日志 / 访问日志分栏切换**（两者量级差得很远，混着看没法用）与**关键词实时过滤**（大小写不敏感的子串匹配，清空输入即恢复全部，命中数随刷新实时更新）。日志直接读 MediaWarp 自己按天写出的 `logs/mediawarp/<日期>/{service,access}.log`，面板不另存副本，因此内容与 `tail -f` 完全一致；未开启文件输出、当天还没日志、关键词无命中三种情况各有独立空态提示，单个文件最多返回最近 2000 行（按行数与字节双上限截断，避免访问日志把面板拖住）。

### 🔧 变更

- **[Logging]**: 日志目录改为**按来源分文件夹**：AutoFilm 的按天日志与任务日志收进 `logs/autofilm/`（任务日志在 `logs/autofilm/task-logs/`），MediaWarp 的 access / service 日志落在 `logs/mediawarp/<YYYY-MM-DD>/`。两个进程共用一个日志挂载点时不再混在同一个目录里；旧版本留在 `logs/` 根目录的按天文件会在下次启动时按同一条保留期规则清理（只认 `YYYY-MM-DD.log`）。
- **[MediaWarp]**: 日志分目录名统一为带前导零的 `YYYY-MM-DD`（原 `2006-1-2` 格式按字符串排序会错位）；并修复**跨月同日不换文件**的问题——原实现只比对「几号」，11-19 打开的文件到 12-19 会被判定成同一天，日志继续写进上个月的分目录，而该目录随后会被保留期清理当成过期目录删掉。

### ⚡ 优化

- **[Logging]**: 日志保留期由 14 天收紧到 **7 天**，AutoFilm 的按天日志、任务日志与 MediaWarp 的日志分目录各自按本地日期清理。清理规则只匹配日期命名的文件 / 目录，且**只删超过 7 天的**：保留期内（含第 7 天当天）与正在写入的当天日志一律不动，其它文件与目录也不碰。

## [3.3.1] - 2026-11-17

### ⚡ 优化

- **[LibraryPoster]**: collage 风格的标题块改为**贴顶排布 + 动态避让海报墙**。原先整块文字以画布 `52%` 高度纵向居中，四字标题（如「日韩美剧」）的右端会压到斜向左下铺开的海报上；现在标题墨迹顶边固定在画面 `33%` 处、副标题向下生长，宽度不再写死 `34%`，而是扫描海报卡片的 alpha 不透明像素、取文字块所在纵向区间内最靠左的可见边缘反推可用宽度（1080p 下留出约 `46px` 间距），再据此定字号——上移腾出的左下角空白被重新利用，任何标题/分辨率下都不会与海报重叠。副标题也从「只画单行、放不下就无限缩字号」改为**优先折行（最多两行）**，仍放不下才缩字号，长英文副标题不会再被压成一串小字；字号、行高、折行结果统一由 `TitleLayout` 度量，缺标题/缺副标题时块高各自收敛。同时**删掉副标题左侧的色标小方块**（以及只服务于它的主题色→强调色推导）：它原本用于给副标题做视觉锚点，但在压暗背景上更像一块噪点，副标题现在与标题左对齐、直接以文字起行。

## [3.1.0] - 2026-11-15

### 🔧 变更

- **[Admin]**: 面板下发的业务配置改为**脱敏副本**：AList 的 `password` / `otp_code` / `token` 与媒体服务器 `api_key` 统一替换为占位符 `__autofilm_masked__`；`/api/config.yaml`「复制备份」导出同样脱敏，并在文件头注明「不能直接用于启动」。占位符原样提交保存时按条目 `id` 还原真实值，用户真正改写或清空的字段以提交内容为准，因此改其它字段不会把密码冲掉。**这是可见的行为变化**：面板密码框点「显示」看到的是占位符，需要明文请直接查磁盘上的 `config.yaml`。
- **[Alist2Strm]**: Windows 下落盘前先规范化远端文件名：`< > : " | ? *` 与控制字符替换为 `_`，结尾空格与点裁掉，`CON` / `NUL` / `COM1` / `LPT1` 等保留设备名加 `_` 前缀。此前这类文件名会让对应条目每轮都写盘失败而被跳过；Linux / Docker 行为完全不变（不做任何重命名）。
- **[Repo]**: `mediawarp/` 由内嵌源码改为 **git submodule**，指向自有 fork [zian-yan/MediaWarp](https://github.com/zian-yan/MediaWarp)（当前锁在 `acbb22d` / tag `v1.2.3`，即此前的 vendored 版本）。主仓库不再跟踪其 81 个 Go 源文件，MediaWarp 的改动改为在子模块内提交并推送，主仓库只记录 gitlink。镜像构建路径不变（仍 `COPY mediawarp/` 编译），但**检出方式变了**：本地需 `git clone --recursive` 或 `git submodule update --init --recursive`；CI 中 `build-docker` 的 `actions/checkout` 已加 `submodules: recursive`，CI 触发路径补上 `mediawarp`（submodule 指针更新在 diff 中表现为单个路径）与 `.gitmodules`。父仓库 `.gitignore` 不再列出 `mediawarp/` 下的本地文件，改由子模块自身的 `.gitignore` 负责。
- **[Admin]**: 侧边栏精简与合并：`Alist2Strm 任务` / `Ani2Alist 任务` 更名为 `Strm 任务` / `Ani 任务`；原先独立的 `同步全局设置` 不再占一个导航入口，改为并入 `Strm 任务` 页面内的分栏（任务 / 全局设置）。两个分栏共用同一个 `config.yaml` 与保存接口，切换时页面标题保持 `Strm 任务`、副标题描述当前分栏；选中状态写入地址栏 hash，刷新与分享后仍停在原分栏，旧的 `#alist2strm` 链接也可直达「全局设置」。

### ⚡ 优化

- **[TaskLog]**: 任务日志满 1024 行后，原来每写一行都要 `File::create` 重写整个文件，且全程持有全局锁做同步 IO。改为按水位整理：追加到 2048 行才整体重写一次，写盘量降低约三个数量级，大库同步的后段不再出现越长越慢的卡顿。
- **[LibraryPoster]**: 海报渲染与 PNG 编码（高斯模糊、拼贴，属秒级纯 CPU 工作）从异步任务移到阻塞线程池，素材解码同样移出。低核数机器上生成海报期间，面板与其它定时任务不再一起卡住。
- **[Alist2Strm]**: 文件系统调用批量化——同一目录每轮只真正创建一次（此前每个文件都 `create_dir_all` 一路 stat 到根）；「本地是否存在」与「伴生文件是否过期」合并为一次 `metadata`；清理阶段的空目录改在删除结束后自深向浅统一处理并按目录去重。
- **[Admin]**: `GET /api/runtime` 计算「下次运行」时不再克隆整份业务配置，改为在只读锁内取任务列表。
- **[Admin]**: 运行日志弹层字号由 `13px` 降到 `10px`（新增 `--t-log` 令牌，行高 `1.6`、内边距收紧），同一屏可多显示近三成日志行；时间戳与 `[WARN]`/`[ERROR]` 级别标记继承行色后降透明度，密度提高但不再糊成一片。
- **[Admin]**: 运行日志按操作类型**整行染色**：`生成`/`更新`/`写入` 为绿、`下载`/`复制` 为橙、`删除` 为红（新增 `--log-fetch` 令牌，深浅主题各一档），动作词加粗，长路径随整行同色，滚动时整块颜色即可分辨操作类型；同一动作在生成、追更、海报等所有任务里颜色一致。
- **[Admin]**: 控制台与登录页整体重构为 macOS / iOS 的「系统质感」：系统蓝强调色、`19px` 大圆角卡片、侧边栏与弹窗的毛玻璃（`backdrop-filter`）、浅色 Apple 灰白与深色「纯黑 + `#1c1c1e` 分组卡片」两套主题、胶囊按钮、填充式表单控件与 iOS 转场曲线。强调色收敛到导航选中、主按钮、焦点环、实时状态四处，「运行所有」降为次级按钮（一屏只有一个实心蓝）；移动端弹窗改为贴底滑出，「保存」独占整行、危险操作固定在左侧。对比度按 WCAG AA 逐项验算，最低 `4.67:1`（深色主题实心按钮底色由 `#0a84ff` 压到 `#0a72e0` 才达标）；键盘焦点环改为「内实线 + 外柔光」双层，不再用 `outline: none` 抹掉可访问性；移动端导航与输入控件抬到 `44px` 以上。
- **[Admin]**: 侧边栏重新分配纵向空间：导航行高由 `36px` 提到 `40px`、项间距翻倍，不再挤成一片；「面板自身」分组连同「Web 面板」用 `margin-top: auto` 推向底部，与业务配置之间的大片留白变成两组之间的间隔；底部由「版本号 / 按钮」上下居中的两行改为一行工具条——版本号收成中性小胶囊靠左，主题与退出按钮改用淡填充圆形靠右。
- **[Admin]**: 页面标题区重新排版：标题字号上限由 `36px` 收到 `32px`（`36px` 在 Windows 上会把中文合成加粗，压过整页层级），标题与副标题间距由 `8px` 提到 `10px`；副标题限宽 `68ch`，并用 `word-break: keep-all` + `overflow-wrap: anywhere` + `text-wrap: balance` 让换行只落在标点处、且两行等长，不再出现「伴生文 / 件」这种拆词或第二行只剩几个字；右上角保存状态胶囊与标题首行视觉居中，状态点加一圈同色光晕；窄屏下状态胶囊换行后由行间距统一控制，不再叠加上对齐偏移。

- **面板**: 新增独立登录页 `/login`（替代浏览器原生 Basic 弹窗）：未登录页面 302 跳转、接口 401，新增 `POST /api/login` / `POST /api/logout`；会话为内存中的随机 token（12 小时滑动过期、上限 128），Cookie 设置 `HttpOnly` + `SameSite=Strict`，右上角提供退出登录，脚本仍可用 HTTP Basic 访问接口。

### 变更

- **[LibraryPoster]**: 媒体服务器认证按 `kind` 分流——Jellyfin 改用 `Authorization: MediaBrowser Token="..."`，兼容 12.0 起默认禁用 `X-Emby-Token` / `?api_key=` 的行为，且向下兼容 10.8+；Emby 保持原有认证方式。Jellyfin 的 API Key 新增字符校验（面板保存与客户端创建时均会拦截含引号、空格等值）。
- **面板**: 移除侧栏的「业务 YAML / 面板 YAML」直链（接口仍保留，只是不再在页面上展示）。

## [1.0.0] - 2026-11-08

首个独立发布版本。相较上游基线，本版本补齐了 Web 管理面板、配置热重载与一整套安全加固，并把面板配置从业务配置中彻底拆分出来。

### ⚠️ 破坏性变更

- **[Config]**: Web 面板配置从业务配置中拆分，改由独立的 `config/web.yaml` 承载（可用 `--web-config` 指定路径）。`config.yaml` 不再接受 `web:` 分区，旧文件中的该段会被忽略并打印一条迁移警告。
  > **迁移说明**：把原 `config.yaml` 中的 `web:` 段内容平移到 `config/web.yaml`（去掉外层 `web:` 键），再从 `config.yaml` 中删除该段。
- **[Config]**: 业务配置与面板配置均允许为空——文件缺失、空文件、仅含注释或 `null` 都会按内置默认值启动，不再报错退出；只有 YAML 语法错误仍然快速失败。
- **[Alist2Strm]**: 移除 `mode` 配置项与 `RawURL` / `AlistPath` 两种 `.strm` 内容模式，`.strm` 统一写入 AList `/d` 直链；旧配置中的 `mode` 字段会被忽略。

### ✨ 新增

- **[Admin]**: 内置 Web 管理面板（静态资源内嵌进二进制，零外部前端依赖）：schema 驱动表单、增删改条目、按 `section[index].field` 定位校验错误、乐观并发控制（版本冲突返回 409）。
- **[Admin]**: 配置热重载内核——校验 → 构建并启动新调度器 → 原子写盘 → 切换 → 停用旧调度器，任一步失败都保留旧配置继续运行。触发来源：面板保存、手工「重新加载文件」、配置文件外部改动（2 秒轮询）。
- **[Admin]**: 业务配置与面板配置各自独立的存储、版本号与接口（`PUT /api/config`、`PUT /api/web`），面板保存互不覆盖；外部编辑与手工重载只读取、不回写，保留注释与排版。
- **[Alist2Strm]**: 智能删除保护：远端目录扫描失败时不参与清理，大批删除先进入宽限确认。
- **[LibraryPoster]**: 支持 Collage / Card / Split / Blur 四种海报渲染风格与自定义分辨率。
- **[Core]**: 任务互斥（同一任务上一轮未结束则跳过本轮）、`.part` 临时文件原子写入、SIGTERM 优雅退出。

### 🔒 安全

- **[Admin]**: HTTP Basic 认证使用定长比较，连续 8 次失败按来源 IP 锁定 60 秒（限流表定期清理并设有容量上限）。
- **[Admin]**: 变更类请求必须携带 `X-AutoFilm-Request: 1`，配合 CSP 与同源限制阻断 CSRF；未设置密码时只允许监听回环地址，否则进程拒绝启动。
- **[Admin]**: 密码与密钥不回传前端（`/api/state`、`/api/config.yaml`、`/api/web.yaml` 均脱敏）。
- **[Config]**: 配置文件（含明文密钥）在 Unix 下按 `0600` 创建，保存时同步收紧权限，`.bak` 备份同样处理。
- **[Alist2Strm]**: 修复远端文件名/路径未规范化导致的目录穿越，并校验最终路径仍位于 `target_dir` 内。

### 🐛 修复

- **[Alist2Strm]**: 修复 AList 目录扫描失败被当作「远端已删除」而清空本地文件的问题。
- **[Alist2Strm]**: 修复智能删除保护的状态文件被同步清理反复删除、导致宽限计数永远无法累积的问题。
- **[Admin]**: 面板保存/重载改为带超时的等待，避免热重载卡住时占满连接名额导致面板假死；连接计数改为原子占用。
- **[Core]**: 修复互斥锁中毒后面板请求永久 panic 的问题。
- **[Ani2Alist]**: UrlTree 写入前清理名称中的冒号与换行，解析/写入/序列化增加深度上限。

### ⚡ 优化

- **[Core]**: AList 客户端补充连接与请求超时，并发 `401` 时只登录一次，避免站点挂起导致任务永久等待。
- **[Core]**: 日志按天切分并保留 14 天，结构化字段贯穿任务与请求上下文。
- **[Admin]**: 面板支持深色/浅色自适应与移动端断点布局。
- **[Release]**: 发布流程收敛为只由 `v*.*.*` 版本 tag 触发，不再在每次 main 分支提交时产出滚动 `pre-release`；Releases 列表只保留正式版本。
- **[Release]**: Docker 镜像标签固定为 `latest` + 语义化版本（`1.0.0` / `1.0` / `1`），不再产出 `main` 分支标签；`docker/compose.yaml` 与文档改为指向本仓库镜像 `ghcr.io/zian-yan/autofilm`。
