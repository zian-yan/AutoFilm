## [3.0.0] - 2026-11-10

### ✨ 新增

- **[MediaWarp]**: 集成 [zian-yan/MediaWarp](https://github.com/zian-yan/MediaWarp) v1.2.3。官方镜像把仓库内 `mediawarp/` 的 Go 源码与 AutoFilm 编译进**同一个容器**，AutoFilm 作为主进程按面板配置生成 `/config/mediawarp.yaml` 并托管代理子进程；侧边栏新增「MediaWarp」入口，提供分组可视化配置面板（服务托管、监听与上游、日志与缓存、客户端过滤、HTTPStrm 302 共 5 组）与服务状态卡片。
- **[MediaWarp]**: 配置保存走完整事务——静态校验 → 原子写生成文件（含 `.bak`）→ SIGTERM 优雅停旧 → 拉起新进程 → 端口健康检查 → 才写 `config.yaml`；任一步失败自动还原文件并用旧配置重新拉起，状态卡片显示失败原因。重启在热重载内核中串行执行，且仅在 MediaWarp 配置或生成文件实际变化时才触发，改其它任务不会打断播放。
- **[Admin]**: MediaWarp 页新增「立即重启」「预览生成的配置」「从文件导入」动作，以及每 3 秒刷新的运行状态（阶段、PID、端口、健康、累计重启、生成文件路径、最近错误）。

### 🔧 变更

- **[Repo]**: 仓库重组为聚合结构：`autofilm/` 放 AutoFilm（Rust）源码、`mediawarp/` 放 MediaWarp（Go）v1.2.3 上游源码（已移除嵌套 `.git`），`.git`、`.github/`、`.agents/`、`.workbuddy/` 保留在仓库根。所有 `cargo` 命令改在 `autofilm/` 下执行，CI 工作流通过 `working-directory` / `autofilm/` 前缀适配；新增根级 `.dockerignore`（排除构建产物与密钥）与聚合版 `.gitignore`。
- **[Docker]**: `autofilm/docker/Dockerfile` 与 `Dockerfile.ci` 改为 `COPY mediawarp/` 本地源码编译，去掉 `git clone` 与 `MEDIAWARP_REF`；构建上下文改为**仓库根目录**（`docker build -f autofilm/docker/Dockerfile .`）。Rust 侧 COPY 路径统一加 `autofilm/` 前缀，并补上 `build.rs` 与 `.git` 供 vergen 生成版本信息。Go 依赖仍由模块代理下载，可用 `go mod vendor` 转为完全离线。
- **[Docker]**: `docker/compose.yaml` 默认映射 `9000` 端口；`config/mediawarp.example.yaml` 提供生成文件示例，生成文件本身已加入 `.gitignore`（含 API Key）。
- **[Admin]**: 配置应用超时由 20 秒放宽到 45 秒，为一次完整的代理重启（停止 5s + 健康检查 10s）留出余量。
- **[Docs]**: 移除仓库内全部 `README.md`，发布包不再附带 README。为避免丢失上游许可要求的归属信息，来源与许可声明改记于此：

  > `mediawarp/` 目录为 [MediaWarp](https://github.com/zian-yan/MediaWarp)（上游 <https://github.com/AkimioJR/MediaWarp>）**v1.2.3** 源码，tag `v1.2.3` / commit `acbb22d5740a3c57f6410cbe15208b11def195ec`，仅用于在同一镜像内编译；嵌套 `.git` 已移除，源码纳入本仓库版本控制。其许可证为修改版 GNU AGPL-3.0（见 `mediawarp/LICENSE`），附加条件包括：归属原作者 AkimioJR、不得用于商业活动、使用或参考其代码须开源修改并明确注明来源。据此声明：**本项目中 MediaWarp 相关代码与实现思路来自 MediaWarp 项目**。AutoFilm 自身许可见 `autofilm/LICENSE`。

## [2.2.1] - 2026-11-10

### ✨ 新增

- **[Admin]**: 控制台与登录页改用「Ink / Paper」编辑式视觉——微暖纸白 / 墨黑中性色阶 + 唯一靛蓝强调色，细线分隔、小圆角、无渐变。建立五级字号契约（页面标题 34px → 卡片标题 19px → 正文 15px → 标签 13px → 辅助 12px）与强调色白名单（只用当前导航项、主按钮、输入焦点环、LIVE 指示），补齐深浅两套主题在桌面 / 平板 / 移动端的响应式；全部类名与交互逻辑不变。
- **[Admin]**: 「同步全局设置」从 Alist2Strm 任务页拆出，成为侧边栏独立入口。它与「Web 面板」是两份互不相干的配置：前者保存在 `config.yaml` 的 `alist2strm`，管并发数、伴生文件下载与同步删除策略，走业务配置接口；后者保存在独立的 `web.yaml`，管监听地址与认证，走面板配置接口。侧边栏新增「— 面板自身 —」分组条把两者隔开，仍是两个独立 section、两套数据源与保存接口，没有合并。

### ⚡ 优化

- **[Alist2Strm]**: 扫描生成改为**按目录分批、目录间严格串行**。一次目录列举返回的 `.strm` 与字幕 / NFO / 图片等伴生文件合为一批在批内并发处理，整批 `await` 完成后才进入下一个目录，日志中目录之间不再交错；新增 `目录处理完成: {目录}（N 个文件）` 作为批次边界标记。原先的全局有界队列只在文件少时才「看起来」是逐目录完成。BDMV 主片仍保持「全局收集 → 扫描结束后统一选片」的第二阶段，未改动。
- **[Alist2Strm]**: 单文件失败只记录并跳过、不阻断同批其它文件；`concurrency` 默认值与配置项本身保持不变。

### 🔧 变更

- **[Alist2Strm]**: `concurrency` 的语义由「全任务在途上限」调整为「单个目录内的并发上限」。小目录无法用满配置值，整体吞吐会略低于此前，这是目录间严格串行的必然代价；配置项名称、默认值与校验规则均不变。

## [2.2.0] - 2026-11-09

### 🔧 变更

- **[Core]**: `alist-client-rs` 由 git submodule 改为仓库内置目录，客户端源码与主仓库同版本演进。此前它的定制补丁只能停留在本地——`.gitmodules` 指向上游仓库、没有推送权限，一条只存在于本机的新提交 CI 无法拉取，构建与发布都复现不出来；内置后 `cargo build` 与发布流水线都不再需要 `submodules: recursive`。
- **[Core]**: 补上 v2.0.0 变更日志中已描述、但当时并未真正进入仓库的客户端补丁：HTTP 连接超时 15 秒、请求整体超时 120 秒，AList 挂起时任务不再永久等待。

### ⚡ 优化

- **[Core]**: 并发请求同时收到 `401` 时只重新登录一次——比对请求前后的令牌是否已被其它请求刷新，并用互斥锁串行化刷新过程，避免重复登录触发 AList 的登录限流。
- **[Core]**: 修复客户端单元测试的偶发失败——mock 服务器原来只读一次请求就回包并关闭连接，请求体稍大的用例会因 TCP 分片收到 `IncompleteMessage`（本机约 50% 复现），改为按 `Content-Length` 读完整个请求再响应。

## [2.1.0] - 2026-11-09

### ✨ 新增

- **[Admin]**: Cron 表达式支持「随机」生成——编辑任务的定时字段右侧新增按钮，一键生成 `<秒> <分> <时> * * *` 表达式（分与时在 `00:00–23:59` 内随机），生成后仍可手改、可保存为固定值。
- **[Alist2Strm]**: 失败目录自动重扫——扫描失败、或目录内有文件处理失败的目录会记录到目标目录下的 `.autofilm_retry_<任务>.json`，下一轮对这些目录连同子树无条件扫描（不受「目录时间检查」影响），避免漏文件；记录以本轮结果覆盖写盘，全部成功即删除文件，不与历史记录叠加。
- **[Alist2Strm]**: 任务新增 `dir_time_check`（面板「目录时间检查」）——开启后仅当远端目录的修改时间晚于本地目录时才扫描其子目录，未变化的子树整棵跳过；被跳过的子目录不参与同步清理，远端目录时间为零值时一律扫描。文件已更新却仍被跳过时关闭本选项即可。
- **[Logging]**: 支持 `TZ` 环境变量解析应用时区（优先级：`--timezone` > `TZ` > 系统时区 > `UTC`），Docker 里 `TZ=Asia/Shanghai` 即可让日志与任务时间落到本地时区；`TZ` 允许空值、`:` 前缀与非法值（非法时自动回退系统时区）。

### ⚡ 优化

- **[Alist2Strm]**: 任务汇总把「跳过目录」（因目录时间未变化而整棵跳过）与「扫描失败目录」拆成两个独立统计，日志分别使用这两个说法，不会再把列目录失败误读成正常跳过；文件级失败改称「文件失败」。
- **[Alist2Strm]**: 生成的 `.strm`、下载的伴生文件与本地目录，时间统一对齐到远端 `created`（缺失/零值时退回 `modified`），媒体库「最近添加」不再被任务运行时间刷成最新；被 `overwrite=false` 跳过的老文件也会补齐时间，已对齐的不重复写盘；目录时间在文件与清理都结束后自深向浅设置。伴生文件的增量判断同步调整：本地时间等于远端创建/修改时间即视为最新，避免每轮重下。
- **[Logging]**: 日志行改为 `11-07 12:21:02 消息` 样式：去掉 target、行号与 INFO 级别，`WARN` / `ERROR` 才带级别标记（终端上色），任务日志面板、控制台与按天文件三处风格一致。
- **[Logging]**: 过滤第三方库的 INFO 噪音（cron 调度器的 `Uninited`、`Job creator created`），这类没有上下文的行在新格式下只剩一个孤立单词，容易与自身日志混淆。
- **[Alist2Strm]**: 任务日志改为「抬头 → 生成 → 清理 → 汇总」的分段输出（`>>> 开始生成`、`读取目录:`、`生成:`、`删除:`、`【生成文件完成】`），一眼看出这轮跑了什么、生成与清理了多少。

## [2.0.0] - 2026-11-08

> 本版本为主版本升级：`v1.1.0` 已包含配置结构的不兼容调整，本版又改变了面板的保存语义与运行中任务的处理方式，按语义化版本统一收敛为 `2.0.0`。

### ⚠️ 破坏性变更

- **[Admin]**: 面板保存入口改为「编辑弹窗 / 分区卡片内的『保存』」，移除顶部的「保存并应用」与「重新加载」按钮；改动不再先攒着统一应用，关闭或取消弹窗会直接丢弃未保存的草稿，单值分区需在卡片内单独保存。
  > **迁移说明**：习惯顶部批量保存的用户改为逐条保存；自动化脚本仍可调用 `PUT /api/config`、`PUT /api/web` 与 `POST /api/reload`，接口保持兼容。
- **[Admin]**: 新增运行中任务配置锁定——正在执行的任务条目不允许修改或删除，面板禁用对应控件，后端返回 `423` 并列出任务名，整次保存不写盘、不推进版本号。
  > **迁移说明**：等待任务结束后再修改该条目，或在一次保存里只改动其它任务；直接编辑 `config.yaml` 时，被锁定条目沿用运行开始时的配置值，其余改动照常应用。
- **[Admin]**: `web.yaml` 的全部字段改为实时生效：切换 `listen` 会热重绑监听端口，`enable` 置为 `false` 会立即停止面板服务，修改认证信息会清空所有登录会话；旧版保存后仅提示「重启生效」。
  > **迁移说明**：改监听地址后请改用新地址访问面板；改密码后所有已登录页面需重新登录。

### ✨ 新增

- **[Admin]**: 任务级运行日志——每个任务新增「日志」按钮，弹层按 500ms 轮询、按时间顺序展示该任务执行期间的日志，支持运行中查看，用户上翻时不强制滚底；数据来自 `POST /api/task-log`。
- **[Logging]**: 新增 `TaskLogLayer` 按任务 span 采集日志并落盘到 `logs/task-logs/`，重启后仍可查看；每个任务最多保留最新 1024 行，超限时同步裁剪磁盘文件，孤儿日志按 14 天清理。
- **[Admin]**: 界面改为侧边栏导航 + 弹窗式配置编辑，编辑与日志弹窗均支持关闭按钮 / `Escape` / 遮罩关闭；移除「总览」页与底部运行状态行，旧 `#overview` 链接自动回落到首个配置分区。
- **[Admin]**: 「同步全局设置」并入「Alist2Strm 任务」页、「媒体库海报」并入「媒体服务器」页，旧链接自动回落到宿主分区。
- **[Admin]**: 新增站点图标 `favicon.ico`（AF 渐变标记，含 16/32/48/64 四档尺寸），启用登录认证时登录页也能正常显示。

### ⚡ 优化

- **[Admin]**: 全站视觉尺寸统一放大约 15%（等价于浏览器 115% 缩放），保留视口单位与固定定位的正确行为；登录页移除凭据存放位置提示。
- **[Schedule]**: 每次启动与热重载按当前任务键清理运行互斥表与任务日志缓存，避免任务 ID 变动后旧条目常驻内存。
- **[Admin]**: 目录浏览弹层与日志弹层补齐请求取消、超时与防重入；状态轮询在无草稿时按版本变化自动刷新，页面长期停留不再产生请求堆积。

### 🐛 修复

- **[Core]**: 修复任务日志读接口为每个未知 `模块:任务ID` 创建永不释放的缓存条目所导致的内存无界增长；实测 24000 次不同键请求后内存趋于平稳。
- **[Admin]**: 修复 Windows 下从非阻塞监听套接字接出的连接继承非阻塞状态、高并发读写报 `os error 10035` 的问题。
- **[Admin]**: 修复日志空态不渲染、运行中状态滞留导致轮询不停、900ms 启动定时器未清理，以及目录弹层关闭后在途请求继续写 DOM 的问题。

## [1.0.0] - 2026-11-08

首个独立发布版本。相较上游基线，本版本补齐了 Web 管理面板、配置热重载与一整套安全加固，并把面板配置从业务配置中彻底拆分出来。

### ⚠️ 破坏性变更

- **[Config]**: Web 面板配置从业务配置中拆分，改由独立的 `config/web.yaml` 承载（可用 `--web-config` 指定路径）。`config.yaml` 不再接受 `web:` 分区，旧文件中的该段会被忽略并打印一条迁移警告。
  > **迁移说明**：把原 `config.yaml` 中的 `web:` 段内容平移到 `config/web.yaml`（去掉外层 `web:` 键），再从 `config.yaml` 中删除该段。
- **[Config]**: 业务配置与面板配置均允许为空——文件缺失、空文件、仅含注释或 `null` 都会按内置默认值启动，不再报错退出；只有 YAML 语法错误仍然快速失败。
- **[Alist2Strm]**: 移除 `mode` 配置项与 `RawURL` / `AlistPath` 两种 `.strm` 内容模式，`.strm` 统一写入 AList `/d` 直链；旧配置中的 `mode` 字段会被忽略。

### ✨ 新增

- **[Admin]**: 内置 Web 管理面板（静态资源内嵌进二进制，零外部前端依赖）：schema 驱动表单、增删改条目、按 `section[index].field` 定位校验错误、乐观并发控制（版本冲突返回 409）。
- **[Admin]**: 配置热重载内核——校验 → 构建并启动新调度器 → 原子写盘 → 切换 → 停用旧调度器，任一步失败都保留旧配置继续运行。触发来源：面板保存、手工「重新加载文件」、配置文件外部改动（2 秒轮询）。
- **[Admin]**: 业务配置与面板配置各自独立的存储、版本号与接口（`PUT /api/config`、`PUT /api/web`），面板保存互不覆盖；外部编辑与手工重载只读取、不回写，保留注释与排版。
- **[Alist2Strm]**: 智能删除保护：远端目录扫描失败时不参与清理，大批删除先进入宽限确认。
- **[LibraryPoster]**: 支持 Collage / Card / Split / Blur 四种海报渲染风格与自定义分辨率。
- **[Core]**: 任务互斥（同一任务上一轮未结束则跳过本轮）、`.part` 临时文件原子写入、SIGTERM 优雅退出。

### 🔒 安全

- **[Admin]**: HTTP Basic 认证使用定长比较，连续 8 次失败按来源 IP 锁定 60 秒（限流表定期清理并设有容量上限）。
- **[Admin]**: 变更类请求必须携带 `X-AutoFilm-Request: 1`，配合 CSP 与同源限制阻断 CSRF；未设置密码时只允许监听回环地址，否则进程拒绝启动。
- **[Admin]**: 密码与密钥不回传前端（`/api/state`、`/api/config.yaml`、`/api/web.yaml` 均脱敏）。
- **[Config]**: 配置文件（含明文密钥）在 Unix 下按 `0600` 创建，保存时同步收紧权限，`.bak` 备份同样处理。
- **[Alist2Strm]**: 修复远端文件名/路径未规范化导致的目录穿越，并校验最终路径仍位于 `target_dir` 内。

### 🐛 修复

- **[Alist2Strm]**: 修复 AList 目录扫描失败被当作「远端已删除」而清空本地文件的问题。
- **[Alist2Strm]**: 修复智能删除保护的状态文件被同步清理反复删除、导致宽限计数永远无法累积的问题。
- **[Admin]**: 面板保存/重载改为带超时的等待，避免热重载卡住时占满连接名额导致面板假死；连接计数改为原子占用。
- **[Core]**: 修复互斥锁中毒后面板请求永久 panic 的问题。
- **[Ani2Alist]**: UrlTree 写入前清理名称中的冒号与换行，解析/写入/序列化增加深度上限。

### ⚡ 优化

- **[Core]**: AList 客户端补充连接与请求超时，并发 `401` 时只登录一次，避免站点挂起导致任务永久等待。
- **[Core]**: 日志按天切分并保留 14 天，结构化字段贯穿任务与请求上下文。
- **[Admin]**: 面板支持深色/浅色自适应与移动端断点布局。
- **[Release]**: 发布流程收敛为只由 `v*.*.*` 版本 tag 触发，不再在每次 main 分支提交时产出滚动 `pre-release`；Releases 列表只保留正式版本。
- **[Release]**: Docker 镜像标签固定为 `latest` + 语义化版本（`1.0.0` / `1.0` / `1`），不再产出 `main` 分支标签；`docker/compose.yaml` 与文档改为指向本仓库镜像 `ghcr.io/zian-yan/autofilm`。
